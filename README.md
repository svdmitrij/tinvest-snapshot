# tinvest-snapshot

Консольная утилита: снимок всех счетов в Т-Инвестициях (позиции, деньги,
доходности, ближайшие выплаты) в файлы JSON и CSV с накоплением истории.

Реализована на чистой стандартной библиотеке Go через официальный REST-шлюз
T-Invest API — единый статический бинарь без внешних runtime-зависимостей.

## Сборка

```
go build -o tinvest-snapshot ./cmd/snapshot        # текущая платформа
./scripts/build.sh                                  # linux/amd64 + windows/amd64 -> dist/
```

## Конфигурация

Скопируйте `config.example.json` в `config.json` рядом с бинарём и заполните.

| Поле | Назначение |
|------|-----------|
| `mode` | `prod` (боевой) или `sandbox` (песочница) |
| `token` | токен API (лучше не хранить здесь — см. `token_env`) |
| `token_env` | имя переменной окружения с токеном (по умолчанию `TINVEST_TOKEN`) |
| `retries` | число повторных попыток при ошибках API |
| `retry_delay_ms` | базовая задержка между попытками (линейный backoff) |
| `reports_dir` | каталог отчётов (по умолчанию — `reports` рядом с бинарём) |
| `target_currency` | валюта пересчёта итогов по умолчанию (`""` — выключено) |
| `endpoint` | переопределение базового URL API (обычно пусто) |

Токен берётся только на чтение и не попадает в логи, вывод и отчёты.

## Запуск

```
export TINVEST_TOKEN=<ваш токен>
./tinvest-snapshot --config config.json
./tinvest-snapshot --config config.json --target-currency usd   # пересчёт итогов в USD
./tinvest-snapshot --config config.json --mode sandbox          # переопределить режим
```

Коды выхода: `0` — успех, `1` — ошибка получения/сохранения данных
(после исчерпания попыток), `2` — ошибка конфигурации/токена.
