# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.7.1] — незавершённый

### Добавлено

- **TLS-настройки в GUI Settings:** два новых поля — `tls_ca_file` (путь к
  PEM-файлу CA-сертификата) и `tls_insecure_skip_verify` (отключение
  проверки TLS-сертификата). Работают через единый Submit-кнопку настроек.
- **Валидация CA-файла:** `config.Load` отклоняет отсутствующий,
  нечитаемый и невалидный PEM с понятным сообщением об ошибке.
- **Приоритет CA > insecure:** при заданном CA-файле `InsecureSkipVerify`
  принудительно игнорируется — сертификат проверяется по указанному CA.

## [1.7.0] — 2026-07-24

Единые адаптивные панели вкладок с общим сбросом и компактным поиском,
динамические каскадные фильтры для любых колонок таблиц, копируемые
сообщения об ошибках и более отказоустойчивая загрузка портфеля и
справочника инструментов.

### Добавлено

- Вкладки «Портфель», «Операции» и «Инструменты» получили единую
  компактную адаптивную панель под панелью вкладок: «Обновить», «Экспорт»,
  масштаб, поле поиска с компактной кнопкой-лупой, группировка и кнопка
  общего сброса «Сбросить всё» (`Reset all`) — в одном относительном
  порядке и с одинаковым цветом кнопок на всех трёх вкладках. На
  «Операциях» поля «Период с»/«Период по» включены в ту же панель. Если
  ширины окна не хватает, элементы переносятся на следующую строку без
  наложения и обрезания; поле поиска и кнопка-лупа всегда переносятся
  вместе.
- Кнопка «Сбросить всё» одним нажатием очищает поиск, группировку и все
  применимые фильтры текущей вкладки (на «Операциях» — также период
  выгрузки) и восстанавливает полную выборку загруженных данных. Сброс
  действует только на открытую вкладку и не влияет на сортировку,
  масштаб, загруженные данные или кэш справочника; повторное нажатие на
  уже нейтральном состоянии не меняет выборку.
- В GUI появились динамические каскадные фильтры для любых отображаемых
  колонок таблиц. Условия задаются отдельными строками, применяются сразу,
  объединяются логическим И и поддерживают типизированное сравнение чисел,
  дат, текста и булевых значений, включая явный фильтр по пустому значению.
- В справочник облигаций добавлена колонка «Квал» из
  `Bond.for_qual_investor_flag`. Значения `true`, `false` и неизвестное `?`
  доступны в таблице, карточке, кэше, динамическом фильтре и экспорте текущего
  вида.

### Исправлено

- На вкладках «Портфель», «Операции» и «Инструменты» убраны внешние
  подписи «Поиск по таблице:», «Группировать по:», «Период с:», «Период
  по:» — подсказки перенесены внутрь соответствующих полей и селектбокса
  (без хвостового «:») и пропадают после ввода значения. Текстовая кнопка
  «Найти далее» заменена компактной квадратной кнопкой с изображением
  лупы с локализованной подсказкой при наведении; поле поиска сохраняет
  прежнюю удобную ширину (не менее 20 символов при масштабе 100%).
  Устранён лишний вертикальный промежуток перед панелью вкладки.
- Очистка строки поиска и последующее нажатие кнопки-лупы снова
  восстанавливают полную выборку (в пределах прочих активных фильтров) —
  ранее прежняя выборка оставалась без изменений.
- Панель динамических фильтров GUI больше не оставляет лишнюю пустую строку
  после удаления последнего условия — остаётся ровно одна пустая строка,
  дубли не накапливаются при повторных циклах удаления/добавления. Кнопка
  `+` теперь отображается только у последней строки панели.
- В колонках дат и чисел значения, не распознанные как дата или число
  (`н/д`, `n/a` и произвольный текст), больше не проходят операцию `>=`
  наравне с обычными значениями: при `>=`/`<=` они трактуются как
  отсутствующие — меньше любого разбираемого значения, как и предусмотрено
  для пустых значений. Сравнение `=`/`!=` не изменилось.
- Высота строки панели фильтров приведена к высоте строки таблицы данных;
  область строк фильтров выделена рамкой, отделяющей её от поиска,
  группировки и таблицы.
- GUI теперь показывает доступный кэш портфеля, операций и инструментов
  сразу, автоматически обновляет таблицы после фоновой загрузки и сохраняет
  лучшие доступные данные при частичной ошибке. Для портфеля добавлен
  настраиваемый тайм-аут `portfolio_load_timeout_seconds` (по умолчанию
  180 секунд); индикатор загрузки остаётся видимым, пока работает хотя бы
  одна операция, а сообщения о тайм-аутах и частичных сбоях содержат понятную
  причину и имя соответствующей настройки.

### Изменено

- В GUI текст сообщений об ошибках теперь можно выделить и скопировать
  стандартной комбинацией клавиш; длинные сообщения отображаются
  в прокручиваемой области.
- Для `instrument_load_timeout_seconds` документирован фактический диапазон
  `1–3600` секунд при значении по умолчанию 600 секунд.

## [1.6.0] — 2026-07-17

Сегментированный кэш справочника инструментов: ленивая загрузка по типам,
независимый TTL, настраиваемые тайм-ауты загрузки, последняя цена
инструмента и фильтр даты погашения через селектбоксы.

### Добавлено

- **Сегментированный кэш справочника.** Пять независимых сегментов:
  облигации, акции, ETF, валюты, фьючерсы — каждый со своей временной
  меткой. TTL проверяется посегментно: ручное обновление одного типа
  не затрагивает остальные. Устаревший плоский кэш автоматически
  мигрирует в сегмент облигаций при первом запуске.
- **Ленивая загрузка инструментов.** При первом открытии вкладки
  «Инструменты» загружаются только облигации (тип по умолчанию).
  Остальные типы — акции, ETF, валюты, фьючерсы — загружаются
  при явном выборе и атомарно добавляются в кэш.
- **Режим «Все».** Показывает локальное объединение всех уже загруженных
  типов без сетевых запросов. Кнопка «Обновить» принудительно загружает
  все пять типов с независимой атомарностью каждого сегмента: успешные
  типы сохраняются, при сбое одного остальные не затрагиваются.
- **Настраиваемые тайм-ауты загрузки.** `instrument_load_timeout_seconds`
  (по умолчанию 600 с, диапазон 30–3600) — тайм-аут полной загрузки
  каталога инструментов. `dividend_load_timeout_seconds` (по умолчанию
  900 с, диапазон 30–3600) — тайм-аут demand-обогащения дивидендами.
  Значения вне диапазона нормализуются к умолчанию.
- **Последняя цена инструмента.** Поле `LastPrice` в справочнике:
  для облигаций — в % от номинала, для фьючерсов — в пунктах, для
  остальных типов — в валюте инструмента. При отсутствии сделки — «н/д».
- **Фильтр даты погашения — селектбоксы.** Поля «от» и «до» заменены
  на выпадающие списки со значениями из данных в таблице.
- **Эффективная дата погашения.** Для облигаций датой погашения
  считается ближайшая будущая оферта; если оферт нет — штатная дата
  из API. Исходная штатная дата сохранена как `contractual_maturity_date`.

### Без изменений

- CLI-режим (`cmd/snapshot`) не затронут — работает как в v1.5.0.
- Поля конфига предыдущих версий обратно совместимы: отсутствующие
  `instrument_load_timeout_seconds` и `dividend_load_timeout_seconds`
  получают значения по умолчанию 600 и 900.
- Кэш портфеля и операций, автообновление, экспорт, локализация,
  часовой пояс — без изменений.

## [1.5.0] — 2026-07-15

Исправление эксплуатационных дефектов GUI v1.4.0: конфиг, загрузка,
масштабирование шрифта, сортировка в группах.

### Исправлено

- **Автоматическое разрешение конфига.** Программа находит или создаёт
  `config.json` без участия пользователя. Порядок: явный `--config` →
  `./config.json` → `%APPDATA%/tinvest-snapshot/` (Windows) /
  `~/.config/tinvest-snapshot/` (Linux) → автосоздание из встроенного
  шаблона. При отсутствии прав на запись показывается GUI-диалог с
  путём. CLI не затронут — по-прежнему требует конфиг явно.
- **Оптимизация загрузки портфеля и операций.** Обогащение позиций
  выполняется параллельно (семафор 6). Справочные вызовы API
  (`InstrumentByUID`, `BondByUID`) кэшируются в памяти с coalesce —
  конкурентные запросы одного инструмента дают ровно один API-вызов.
  Окно купонов сужено с 31 года до 6 лет (−1/+5). В статусной строке
  отображается прогресс: «Загрузка… (N/M)» для портфеля и
  «Загрузка операций… (N/M)» для операций.
- **Масштабирование шрифта.** На каждой вкладке (кроме «Настройки»)
  добавлены кнопки **A−** / **A+** с индикатором масштаба (60–200%,
  шаг 10%). Масштаб применяется немедленно к тексту ячеек и заголовкам
  колонок, сохраняется в `config.json` независимо для каждой вкладки.
  Экспорт не зависит от масштаба.
- **Сортировка внутри групп.** При активной группировке сортировка
  работает внутри каждой группы независимо по выбранному столбцу,
  сохраняя порядок самих групп. Переключение asc/desc меняет
  направление внутри групп; свёрнутая группа при разворачивании
  сохраняет порядок строк.

## [1.4.0] — 2026-07-15

Desktop-приложение на Fyne: портфель, операции, поиск и фильтрация
инструментов Т-Инвест — в табличном интерфейсе уровня Excel/DBeaver.

### Добавлено

- **GUI-приложение** (`cmd/gui`) на Fyne v2.6.3: четыре вкладки — портфель,
  операции, инструменты, настройки. Единая кодовая база для Linux и Windows
  (amd64), статический бинарь без внешних рантаймов.
- **Портфель:** позиции, свободные деньги, итоги по счетам и общий итог —
  со всеми полями CLI-схемы. Для облигаций — купонная ставка, доходности,
  частота и ближайший купон, уровень риска; для акций — данные о дивидендах.
  Кнопка экспорта создаёт полный комплект отчётов (JSON, CSV портфеля,
  CSV операций, XLSX). Пересчёт итогов в целевую валюту с отображением курса.
- **Операции:** таблица со всеми полями CLI-схемы. Период задаётся в
  интерфейсе (поля «с»/«по»); при пустых полях — автоопределение начала
  периода по последнему файлу отчёта. Экспорт текущего вида в CSV и XLSX.
- **Инструменты:** поиск по тикеру, названию и ISIN (регистронезависимо,
  по подстроке) среди пяти типов — акции, облигации, ETF, валюты, фьючерсы.
  Фильтры по облигациям: валюта, частота купона, уровень риска, месяц
  ближайшего купона, тип купона (фикс/флоатер), диапазон ставки купона.
  Фильтры по акциям: валюта, биржа, сектор, дивиденды. Все фильтры
  комбинируются (логическое И).
- **Таблицы:** сортировка по любой колонке кликом по заголовку (▲/▼),
  фильтрация по значению колонки, группировка со сворачиванием/разворачиванием
  групп, текстовый поиск с навигацией по совпадениям. Зебра-подсветка строк.
- **Карточка инструмента:** левый клик по строке таблицы открывает диалог
  с полными параметрами инструмента и ссылкой «Открыть на сайте
  Т-Инвестиции» (tbank.ru). Правый клик по ячейке — копирование значения
  в буфер обмена.
- **Кэш справочника:** справочник инструментов сохраняется локально
  и обновляется автоматически при устаревании (срок задаётся в настройках).
  Кнопка принудительного обновления. Время последнего обновления отображается
  в интерфейсе.
- **Автообновление:** данные портфеля и операций обновляются по таймеру
  (настраиваемый интервал, можно отключить) и по кнопке «Обновить».
- **Настройки:** режим API (prod/sandbox), источник токена (переменная
  окружения или значение в конфиге), повторы и задержка, каталог отчётов,
  целевая валюта, интервал автообновления, срок жизни кэша, язык интерфейса,
  часовой пояс. Сохраняются в `config.json` между запусками.
- **Локализация:** русский и английский интерфейс, переключение без
  пересборки. Тексты вынесены в JSON-файлы, добавление языка = добавление
  файла перевода.
- **Часовой пояс:** время операций и обновления справочника отображается
  в выбранном часовом поясе (UTC±N, по умолчанию +4).
- **Экспорт текущего вида:** любая таблица (с применёнными фильтрами,
  сортировкой и группировкой) экспортируется в CSV и XLSX.
- Сборочный скрипт `scripts/build-gui.sh` — кросс-сборка GUI под Linux
  и Windows.

### Без изменений

- CLI-режим (`cmd/snapshot`) полностью сохранён: флаги, коды выхода,
  форматы и именование файлов — обратная совместимость с v1.3.1.
- Конфиг (`config.json`) обратно совместим: GUI-поля (`auto_refresh_minutes`,
  `catalog_ttl_hours`, `language`, `timezone_offset`) опциональны
  и игнорируются CLI.
- Схема данных портфеля, операций, доходностей облигаций — без изменений.

### Известные ограничения

- GUI требует графическую сессию (X11/Wayland на Linux); на headless-серверах
  используйте CLI.
- `mode: sandbox` не работает для GUI (API возвращает HTTP 500) — как и для CLI.
- Кэш справочника не содержит токен и хранится в `$XDG_CACHE_HOME` или
  `%LocalAppData%`.

## [1.3.0] - 2026-07-10

Выгрузка операций по всем счетам за период и отчёт в формате XLSX — снимок
портфеля дополнен историей сделок, комиссий, пополнений/выводов, купонов,
дивидендов и налогов.

### Добавлено

- Выгрузка операций по всем счетам за период: сделки, комиссии,
  пополнения/выводы, купоны, дивиденды, налоги и прочие типы, которые отдаёт
  API, без фильтрации. По каждой операции — идентификатор, счёт, дата и
  время, тип (человекочитаемо), инструмент (если применимо), количество,
  сумма и валюта, статус. Выборка постраничная (по курсору), поэтому за один
  запуск выгружается вся история независимо от объёма; ретраи (`retries`,
  `retry_delay_ms`) применяются и к запросам операций.
- Флаги `--from <ГГГГ-ММ-ДД>` и `--to <ГГГГ-ММ-ДД>` — задают период выгрузки
  операций. Начало периода определяется по приоритету: явный `--from` →
  автоопределение по дате самого позднего файла `portfolio_*`/`operations_*`
  в каталоге отчётов (день включительно) → дата открытия каждого счёта, если
  флаг не задан и подходящих файлов нет. Конец периода по умолчанию — момент
  запуска, либо `--to` (по 23:59:59 указанной даты). Неверный формат даты или
  `--from` позже `--to` — ошибка конфигурации, код выхода 2, без обращения к
  API.
- Новый файл `operations_<штамп>.csv` — операции за период, отдельно от
  снимка портфеля; `portfolio_<штамп>.json` дополнен ключами
  `operations_period` (фактические границы выгрузки) и `operations[]`, без
  изменения существующей структуры снимка.
- Новый файл `portfolio_<штамп>.xlsx` — снимок портфеля и операции на двух
  листах («Портфель», «Операции»), построчно эквивалентных соответствующим
  CSV-файлам; открывается в Excel и LibreOffice Calc. Зависимость —
  [`github.com/xuri/excelize`](https://github.com/xuri/excelize) (чистый Go,
  не требует CGO).
- Консольная сводка дополнена числом выгруженных операций, фактическим
  периодом выгрузки и полным списком всех четырёх созданных файлов.

### Без изменений

- Формат и имя файлов снимка портфеля (`portfolio_<штамп>.json/.csv`),
  существующие флаги (`--config`, `--target-currency`, `--mode`), коды
  выхода 0/1 и расчёт доходностей облигаций — обратная совместимость с
  1.2.0 сохранена, конфиг и запуск без новых флагов работают как раньше.

### Известные ограничения

- Операции на стыке периодов соседних запусков не дедуплицируются — при
  повторном запуске без `--from` возможны дубли операций за день последнего
  файла.
- Суммы операций не пересчитываются в `target_currency` и приводятся только
  в валюте самой операции.

## [1.2.0] - 2026-07-09

Первый задокументированный релиз утилиты — снимок портфеля Т-Инвестиций в
JSON и CSV с накоплением истории запусков.

### Добавлено

- Снимок всех счетов: по каждой позиции — тикер/ISIN, название, тип,
  количество, средняя и текущая цена, стоимость, прибыль/убыток (абсолютная
  и в процентах); свободные деньги одной записью на валюту; итоги по счёту и
  общий итог по портфелю.
- Для облигаций: купонная ставка, периодичность выплат, дата и сумма
  ближайшего купона, кредитный рейтинг из API. Текущая доходность и
  доходность к погашению (YTM) вычисляются из графика купонов, цены,
  номинала и НКД — API их не отдаёт готовыми. YTM считается только для
  облигаций с фиксированным купоном без амортизации и без признака
  бессрочности.
- Для акций: сумма последней выплаченной дивидендной выплаты, периодичность
  за последние 12 месяцев, дата и сумма ближайшей объявленной выплаты.
- Флаг `--target-currency`: пересчёт итогов по счетам и по портфелю в целом
  по курсу из API, с указанием использованного курса.
- Отчёты пишутся в именованные по времени запуска файлы (не перезаписывают
  предыдущие запуски); каталог отчётов задаётся конфигом; ретраи с линейной
  задержкой при временных ошибках API; ненулевой код выхода при сбое;
  консольная сводка после каждого запуска.
- Единый статический бинарь (только стандартная библиотека Go, REST-шлюз
  T-Invest API), кросс-сборка под Linux и Windows (amd64). Токен API
  используется только на чтение, передаётся исключительно в заголовке
  запроса и не попадает в логи, консольный вывод или отчёты.

### Исправлено

- Свободные деньги на счёте агрегировались некорректно при наличии
  нескольких записей в одной валюте — теперь суммируются в одну запись на
  валюту.
- Точность поля `rate` (курс пересчёта) при конвертации итогов в целевую
  валюту.
- Диагностические сообщения приведены к русскому языку.

### Известные ограничения

- `mode: sandbox` — внешнее тестовое окружение T-Invest API отвечает HTTP 500
  на все запросы; это ограничение окружения API, не утилиты. Логика песочницы
  идентична боевому режиму и покрыта юнит-тестами.
