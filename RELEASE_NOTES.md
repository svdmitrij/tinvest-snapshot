# Release notes — v1.8.0 (2026-07-30)

Рекомендуемая версия по SemVer: **1.8.0** (minor). Релиз добавляет нативные
пакеты (deb, rpm, msi) и иконку приложения без изменения существующих форматов,
CLI-поведения или полей конфигурации — поэтому это не major-релиз.

## Обзор

Релиз добавляет нативные установочные пакеты для трёх платформ: Debian/Ubuntu
(`.deb`), RHEL/Fedora (`.rpm`) и Windows (`.msi`). Пользователи могут установить
и удалить приложение штатными средствами ОС (`dpkg`, `rpm`/`dnf`, `msiexec`).
Пакеты включают GUI-бинарь, CLI-бинарь, документацию, пример конфигурации,
иконку приложения в стиле биржевого терминала и интеграцию в меню программ.

Существующие форматы распространения (tar.gz для Linux, tar.gz/zip для Windows)
сохранены без изменений.

## Основные изменения

- **deb-пакет** для Debian/Ubuntu: `dpkg -i` устанавливает бинари
  в `/opt/tinvest-snapshot/`, симлинки в `/usr/local/bin/`, desktop-файл
  (раздел «Офис»), иконку 128×128 и документацию.
- **rpm-пакет** для RHEL/Fedora: `rpm -i` или `dnf install` с тем же
  наполнением.
- **msi-пакет** для Windows: GUI-инсталлятор с выбором пути, ярлык
  в меню «Пуск», запись в «Установка и удаление программ», добавление
  в PATH. Поддерживается тихая установка (`msiexec /qn`).
- **Иконка приложения:** свечной график на тёмном фоне, линии тренда
  и скользящих средних. Исходный SVG и сгенерированные PNG/ICO — в
  `assets/`. Генератор иконок — `cmd/icon-gen` (чистый Go, без внешних
  зависимостей).
- **Desktop-файл** для Linux: `tinvest-snapshot.desktop` запускает GUI,
  категории `Office;Finance;`.
- **Сборка пакетов** интегрирована в `scripts/package.sh`. При отсутствии
  сборочных инструментов (`wixl`, `mingw-w64`) соответствующий артефакт
  пропускается с предупреждением.

## Совместимость и обновление

- Полностью обратно совместимо с v1.7.0. Существующие `config.json`
  продолжают работать без изменений.
- CLI-режим (`cmd/snapshot`), формат отчётов, коды выхода не затронуты.
- Для пользователей, установивших приложение из tar.gz/zip ранее —
  пакетная установка параллельна (файлы в других путях). Рекомендуется
  удалить старые файлы вручную после проверки пакетной установки.
- Действие не требуется — обновление не меняет схему данных и не требует
  миграции кэша или конфигурации.

## Известные ограничения

- msi-пакет не подписан сертификатом Authenticode — SmartScreen может
  показать предупреждение при первом запуске.
- deb и rpm не добавляют репозиторий apt/yum — обновление версий
  выполняется вручную скачиванием нового пакета.
- Сборка msi требует `wixl` из пакета `msitools` (Linux). При отсутствии —
  msi не собирается, но tar.gz/zip доступны.
- Сборка GUI под Windows требует `x86_64-w64-mingw32-gcc`.

# Release notes — v1.7.0 (2026-07-24)

Рекомендуемая версия по SemVer: **1.7.0** (minor). Все изменения этого
релиза добавляют функциональность и исправляют дефекты без удаления или
изменения существующих флагов, форматов файлов и полей конфигурации —
поэтому это не major-релиз. Патч-версией (`1.6.3`) релиз не является,
так как добавлена новая пользовательская функциональность (единые
адаптивные панели, динамические фильтры), а не только исправления.

## Обзор

Релиз объединяет пять завершённых задач с `v1.6.2`: единый адаптивный
интерфейс таблиц GUI (панели, поиск, сброс), сквозную динамическую
фильтрацию, копируемые сообщения об ошибках и более отказоустойчивую
загрузку портфеля и справочника инструментов.

## Основные изменения

- **Единые адаптивные панели вкладок.** «Портфель», «Операции» и
  «Инструменты» используют одну и ту же компактную панель под панелью
  вкладок: «Обновить», «Экспорт», масштаб, поле поиска с компактной
  кнопкой-лупой, группировка, кнопка общего сброса «Сбросить всё» —
  в едином порядке, стиле и с адаптивным переносом по ширине окна. На
  «Операциях» в ту же панель включены поля периода.
- **Кнопка общего сброса «Сбросить всё» / `Reset all`.** Одним нажатием
  очищает поиск, группировку и фильтры текущей вкладки (на «Операциях» —
  также период) и восстанавливает полную выборку. Действует только на
  открытую вкладку, не трогает сортировку, масштаб, загруженные данные и
  кэш; повторное нажатие безопасно.
- **Локализованные placeholders вместо внешних подписей.** Поиск,
  группировка и поля периода операций показывают подсказку внутри поля
  (RU/EN) вместо отдельной строки с подписью и вместо `(Select one)`.
- **Динамические каскадные фильтры таблиц.** Для любой отображаемой
  колонки любой таблицы можно задать произвольное число условий
  (`>=`, `<=`, `=`, `!=`) с типизированным сравнением чисел, дат, текста
  и булевых значений, включая явный фильтр по пустому значению.
- **Колонка «Квал» для облигаций** — признак необходимости статуса
  квалифицированного инвестора (`Bond.for_qual_investor_flag`) в таблице,
  карточке, кэше, фильтре и экспорте.
- **Копируемые сообщения об ошибках** — текст в диалогах ошибок GUI
  теперь выделяется и копируется стандартной комбинацией клавиш; длинные
  сообщения отображаются в прокручиваемой области.
- **Надёжность загрузки.** Кэш портфеля, операций и справочника
  отображается сразу при запуске и обновляется в фоне; при частичной
  ошибке сохраняются лучшие доступные данные. Добавлен настраиваемый
  тайм-аут `portfolio_load_timeout_seconds` (по умолчанию 180 с).

## Совместимость и обновление

- Полностью обратно совместимо с `v1.6.2`. Существующий `config.json`
  продолжает работать без изменений; новый параметр
  `portfolio_load_timeout_seconds` при отсутствии в файле получает
  значение по умолчанию 180 секунд.
- Нижняя граница `instrument_load_timeout_seconds` расширена до 1 секунды
  (ранее 30) для диагностических целей; поведение по умолчанию (600 с)
  не изменилось.
- CLI-режим (`cmd/snapshot`), формат отчётов и коды выхода не затронуты.
- Действие не требуется — обновление не меняет схему данных и не требует
  миграции кэша или конфигурации.

## Известные ограничения

- GUI требует графическую сессию (X11/Wayland на Linux); на
  headless-серверах используйте CLI.
- `mode: sandbox` не работает для GUI и CLI — внешнее тестовое окружение
  T-Invest API отвечает HTTP 500 на все запросы.
