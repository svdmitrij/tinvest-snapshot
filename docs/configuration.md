# Конфигурация tinvest-snapshot

GUI и CLI используют один файл конфигурации — `config.json`.

## config.example.json

```json
{
  "mode": "sandbox",
  "token": "",
  "token_env": "TINVEST_TOKEN",
  "retries": 3,
  "retry_delay_ms": 1000,
  "reports_dir": "reports",
  "target_currency": "",
  "endpoint": "",
  "app_name": "tinvest-snapshot",
  "auto_refresh_minutes": 0,
  "catalog_ttl_hours": 24,
  "instrument_load_timeout_seconds": 600,
  "dividend_load_timeout_seconds": 900,
  "language": "ru",
  "timezone_offset": 4
}
```

## Параметры

### Общие (CLI и GUI)

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `mode` | строка | `sandbox` (пустое → `sandbox`) | Режим API: `prod` (боевой контур) или `sandbox` (песочница). |
| `token` | строка | `""` | Токен API напрямую в конфиге. **Не рекомендуется** — используйте `token_env`. Никогда не записывается в логи, вывод или отчёты. |
| `token_env` | строка | `TINVEST_TOKEN` (если и `token`, и `token_env` пусты) | Имя переменной окружения с токеном. Приоритет: если переменная задана и непуста — используется она; иначе используется `token`. |
| `retries` | число | `3` (< 0 → 0) | Число дополнительных попыток при временных ошибках API. Всего запросов: `retries + 1`. |
| `retry_delay_ms` | число, мс | `1000` (≤ 0 → 1000) | Базовая задержка между попытками; линейная backoff: `delay × номер_попытки`. |
| `reports_dir` | строка | `reports/` рядом с бинарём | Каталог для JSON/CSV/XLSX-отчётов. Создаётся автоматически. |
| `target_currency` | строка | `""` (пересчёт выключен) | Валюта пересчёта итогов в нижнем регистре: `usd`, `eur`, `cny` и др. Пустая строка — без пересчёта. |
| `endpoint` | строка | `""` (официальный URL) | Переопределение базового URL API. Если пусто: `prod` → `https://invest-public-api.tinkoff.ru/rest`, `sandbox` → `https://sandbox-invest-public-api.tinkoff.ru/rest`. |
| `app_name` | строка | `tinvest-snapshot` | Значение HTTP-заголовка `x-app-name` для аналитики T-Invest API. |

### GUI (игнорируются CLI)

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `auto_refresh_minutes` | число | `0` (отключено) | Интервал автоматического обновления портфеля и операций в минутах. `0` — автообновление выключено. Задаётся целым положительным числом. |
| `catalog_ttl_hours` | число | `24` (≤ 0 → 24) | Срок жизни кэша справочника инструментов в часах. Применяется посегментно от времени последней успешной загрузки каждого типа. При устаревании сегмент автоматически перезагружается. |
| `instrument_load_timeout_seconds` | число | `600` (30–3600) | Тайм-аут полной сетевой загрузки инструментов (каталог + обогащение облигаций), в целых секундах. Применяется при загрузке облигаций и при ручном обновлении в режиме «Все». Значения вне диапазона приводятся к 600. |
| `dividend_load_timeout_seconds` | число | `900` (30–3600) | Тайм-аут demand-обогащения дивидендами для акций, в целых секундах. Применяется только к пути дивидендного обогащения. Значения вне диапазона приводятся к 900. |
| `language` | строка | `ru` (пустое → `ru`) | Язык интерфейса. Допустимые значения: `ru` (русский), `en` (английский). Файлы перевода: `cmd/gui/i18n/ru.json`, `cmd/gui/i18n/en.json`. |
| `timezone_offset` | число, UTC±N | `4` (отсутствие поля → 4) | Часовой пояс для отображения времени операций и даты обновления справочника. Допустимый диапазон: от −23 до +23. Значения вне диапазона приводятся к `4`. Отсутствие поля (`null`/не задано) трактуется как `+4`; явный `0` означает UTC+0. |

## Источник токена

Токен API определяется по следующим правилам:

1. Если `token_env` задан и переменная окружения с этим именем существует
   и непуста — используется она.
2. Иначе используется `token` из конфига.
3. Если оба источника пусты — ошибка конфигурации.

Рекомендуется задавать токен через переменную окружения (`token_env`),
а в конфиге оставлять `token: ""`. Это исключает попадание токена в
историю git и бекапы.

Пример:
```bash
export TINVEST_TOKEN=t.ABCDEF1234567890...
./tinvest-gui-linux-amd64
```

Токен ни при каких обстоятельствах не записывается в:
- логи и консольный вывод,
- экспортированные файлы (JSON, CSV, XLSX),
- кэш справочника,
- интерфейс GUI (поле в настройках — `PasswordEntry`, скрывает ввод).

## Каталог кэша

Кэш справочника инструментов сохраняется в системный каталог кэша
пользователя:
- **Linux:** `$XDG_CACHE_HOME/tinvest-snapshot/catalog.json` или
  `~/.cache/tinvest-snapshot/catalog.json`
- **Windows:** `%LocalAppData%/tinvest-snapshot/catalog.json`

Кэш не содержит токен и безопасен для резервного копирования.

## Совместимость

- GUI-поля (`auto_refresh_minutes`, `catalog_ttl_hours`, `language`,
  `timezone_offset`) являются опциональными — при их отсутствии в конфиге
  используются значения по умолчанию.
- CLI игнорирует GUI-поля — один и тот же `config.json` работает
  и в GUI, и в CLI без изменений.
- При добавлении новых полей в будущих версиях обратная совместимость
  сохраняется: отсутствующее поле → значение по умолчанию.
