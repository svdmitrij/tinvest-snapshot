# Эксплуатация tinvest-snapshot (GUI)

## Запуск и первое окно

При запуске GUI открывается окно с четырьмя вкладками:

- **Портфель** — снимок портфеля (позиции, деньги, итоги)
- **Операции** — список операций за период
- **Инструменты** — поиск и фильтрация инструментов на бирже
- **Настройки** — конфигурация приложения

При первом запуске, если кэш отсутствует, таблицы портфеля и операций пусты.
Нажмите «Обновить» на нужной вкладке — приложение загрузит данные из API и
заполнит таблицу. Если кэш уже существует, он отображается сразу, включая
устаревшие данные, пока выполняется фоновое обновление.

## Вкладка «Портфель»

Отображает снимок всех счетов пользователя:

- **Позиции** (`position`) — строка на каждый инструмент в портфеле:
  тикер, ISIN, название, валюта, количество, средняя и текущая цена,
  стоимость, прибыль/убыток. Для облигаций — купонная ставка, доходности,
  частота и дата ближайшего купона, уровень риска. Для акций — данные
  о дивидендах.
- **Свободные деньги** (`cash`) — одна строка на валюту на каждом счёте.
- **Итог счёта** (`account_total`) — суммарная стоимость позиций и денег
  по счёту.
- **Общий итог** (`grand_total`) — сумма по всем счетам в каждой валюте.
- **Общий итог (пересчёт)** (`grand_converted`) — если задана целевая
  валюта в настройках.

Отсутствующие данные отображаются как `н/д`.

**Кнопки:**

| Кнопка | Действие |
|---|---|
| **Обновить** | Загрузить актуальные данные из API |
| **Экспорт** | Сохранить полный комплект отчётов (JSON + CSV портфеля + CSV операций + XLSX) в выбранный каталог |

## Вкладка «Операции»

Отображает список операций за период. Поля: ID, счёт, дата и время,
тип операции, инструмент, количество, сумма и валюта, статус.

**Управление периодом:**

- Поля периода расположены в общей адаптивной панели вкладки, перед
  кнопками «Обновить»/«Экспорт», без отдельных подписей над ними. Пустое
  поле показывает подсказку «Период с» или «Период по»; после выбора
  даты подсказка исчезает и заменяется значением, после очистки поля —
  появляется снова.
- Если оба поля пусты — начало периода определяется автоматически
  (по дате последнего файла отчёта или дате открытия счёта), конец —
  момент запуска.
- Дата «с» позже даты «по» — ошибка валидации в интерфейсе, запрос
  к API не выполняется.
- Кнопка «Сбросить всё» в конце панели очищает оба поля периода вместе
  с поиском, группировкой и фильтрами вкладки — см. «Единая адаптивная
  панель» и «Общий сброс» в разделе «Работа с таблицами».

**Кнопки:**

| Кнопка | Действие |
|---|---|
| **Обновить** | Перезагрузить портфель и операции за заданный период |
| **Экспорт** | Сохранить текущий вид таблицы операций в CSV и XLSX |

## Вкладка «Инструменты»

Поиск инструментов на бирже Т-Инвест. При первом открытии вкладки
автоматически загружаются облигации (тип по умолчанию). Остальные типы
(акции, ETF, валюты, фьючерсы) подгружаются при явном выборе; режим
**«Все»** показывает локальное объединение уже загруженных типов без
сетевых запросов. Изменения критериев применяются автоматически; сетевой
запрос выполняется только при загрузке или принудительном обновлении
справочника. Фильтрация выполняется единой динамической панелью над
таблицей; отдельной кнопки применения условий нет.

### Динамическая панель фильтров

Панель состоит из строк с полями **«Колонка»**, **«Операция»** и
**«Значение»**, а также кнопок `+` и `x`. После выбора всех трёх полей
условие применяется немедленно, без кнопки применения. Неполная строка
результат не ограничивает.

- `+` отображается только у последней строки панели и добавляет новую пустую
  строку в конец; одна колонка может использоваться в нескольких строках.
- `x` удаляет строку. После удаления последней строки остаётся ровно одна
  пустая строка (дубли не накапливаются даже при повторных циклах
  «удалить всё → добавить → удалить всё»).
- Все заполненные строки объединяются логическим И.
- Список значений строится каскадно по строкам, прошедшим остальные условия,
  но без собственного условия строки. Значение, введённое вручную, не
  исчезает после пересчёта списка.
- Для чисел, денег, процентов, дат и текста доступны `>=`, `<=`, `=` и `!=`.
  Числа сравниваются численно, даты — по календарной дате, текст — в том же
  лексикографическом порядке, что и сортировка.
- Для булевых колонок доступны только `=` и `!=`; значение выбирается из
  `true` и `false`, ручной ввод недоступен.
- Первым вариантом небулевого списка является пустое значение. `= пусто`
  оставляет строки с пустым отображаемым значением, `!= пусто` — заполненные;
  при `>=` и `<=` пустое значение меньше любого непустого.
- В колонках дат и чисел значение, которое не удаётся разобрать как дата или
  число (например, `н/д`, `n/a` или произвольный текст), при `>=` и `<=`
  трактуется как отсутствующее — меньше любого разбираемого значения:
  `>= <дата или число>` такие строки не выводит, `<= <дата или число>`
  выводит их вместе со строками, значение которых не превышает указанное.
  При `=` и `!=` такие значения сравниваются как обычный текст, без изменений.

Строки панели по высоте равны строкам таблицы данных (расхождение не более
2 px), а область строк фильтров выделена рамкой, отделяющей её от строки
поиска, селектора группировки и таблицы.

Для облигаций в таблице присутствует колонка **«Квал»**. Она отражает
`Bond.for_qual_investor_flag` из T-Invest API: `true` означает необходимость
статуса квалифицированного инвестора, `false` — отсутствие такого требования,
`?` — отсутствие значения в ответе API. «Квал» также показывается в карточке
облигации, сохраняется в кэше справочника и входит в экспорт текущего вида.
В динамической панели `true`/`false` обрабатываются как булевы значения,
а `?` доступно как отдельное неизвестное значение.

### Кэш и обновление справочника

Справочник состоит из пяти сегментов (облигации, акции, ETF, валюты,
фьючерсы). Каждый сегмент имеет свою временную метку; TTL
(`catalog_ttl_hours`) проверяется независимо для каждого сегмента.

- **Первое открытие** вкладки — загружаются только облигации.
  Остальные типы подгружаются лениво при выборе.
- **Кнопка «Обновить»** при конкретном типе перезагружает только его;
  остальные сегменты не затрагиваются.
- **«Обновить» в режиме «Все»** принудительно загружает все пять
  типов с независимой атомарностью: успешные сохраняются, при сбое
  одного остальные не затрагиваются.
- **Тайм-ауты:** для полной загрузки инструментов —
  `instrument_load_timeout_seconds` (по умолчанию 600 с, допустимо 1–3600 с),
  для дивидендного обогащения акций — `dividend_load_timeout_seconds`
  (по умолчанию 900 с). Значение таймаута загрузки инструментов вне диапазона
  нормализуется к 600 с.
- Устаревший кэш отображается сразу. После завершения загрузки таблица
  обновляется автоматически; при частичной ошибке остаются старый кэш и
  успешно загруженные типы. Ошибка перечисляет локализованные типы и причину.
- Пока активна хотя бы одна загрузка, строка состояния непрерывно показывает
  индикатор загрузки. Повторное нажатие «Обновить» не создаёт параллельную
  загрузку того же типа.
- При переключении на уже загруженный тип сетевые запросы не выполняются.

Под панелью фильтров отображается время последнего обновления
(в часовом поясе из настроек) — для сегмента облигаций.

**Кнопки:**

| Кнопка | Действие |
|---|---|
| **Обновить** | Принудительно перезагрузить текущий тип (или все типы в режиме «Все») |
| **Экспорт** | Сохранить текущий вид результатов в CSV и XLSX |

## Работа с таблицами

Все таблицы в GUI (портфель, операции, инструменты) имеют единый набор
операций:

### Единая адаптивная панель

Вкладки «Портфель», «Операции» и «Инструменты» используют одну и ту же
компактную панель непосредственно под панелью вкладок — без отдельной
пустой строки или зарезервированного промежутка перед ней. Слева
направо: «Обновить», «Экспорт», масштаб (`A−` / `A+` / индикатор
процента), поле поиска с кнопкой-лупой, группировка, «Сбросить всё». На
вкладке «Операции» перед этими элементами, в том же относительном
порядке, расположены поля «Период с» и «Период по».

Кнопки «Обновить», «Экспорт», `A−`, `A+`, кнопка-лупа и «Сбросить всё»
имеют одинаковый цвет и визуальный стиль на всех трёх вкладках.

Если ширины окна достаточно, все элементы панели находятся в одной
строке. При нехватке ширины элементы переносятся на следующую строку в
том же порядке; ничего не перекрывается и не обрезается. Поле поиска и
соседняя кнопка-лупа всегда переносятся вместе, как один блок, и не
сжимаются меньше ёмкости в 20 введённых символов (RU и EN) при масштабе
100%. Компоновка остаётся рабочей при минимальном поддерживаемом
размере окна 640×480 (доступ к скрытым элементам — через штатную
вертикальную прокрутку) и при увеличении ширины окна.

### Сортировка

Клик по заголовку колонки сортирует строки по этой колонке. Повторный
клик меняет направление: ▲ (по возрастанию) ↔ ▼ (по убыванию). Числовые
значения сортируются как числа, текстовые — лексикографически.

### Динамическая фильтрация

1. В строке панели выберите колонку.
2. Выберите доступную операцию.
3. Выберите значение из списка или введите его вручную.
4. Таблица обновится сразу после заполнения строки.
5. Нажмите `+` (доступна только в последней строке), чтобы добавить ещё одно
   условие; нажмите `x`, чтобы удалить строку.

### Группировка

1. Выберите колонку в выпадающем списке группировки. Пока колонка не
   выбрана, список показывает подсказку «Группировать по» (вместо
   подписи над ним и вместо `(Select one)`); после выбора подсказка
   заменяется названием выбранной колонки.
2. Строки сгруппируются по значению выбранной колонки.
3. Клик по заголовку группы (▾ `Группа: значение`) сворачивает группу
   (остаётся только заголовок с ▸). Повторный клик — разворачивает.
4. Выберите пустое значение в списке — группировка снимается, подсказка
   «Группировать по» появляется снова.

### Текстовый поиск

1. Введите текст в поле поиска. Пока поле пусто, оно показывает
   подсказку «Поиск» вместо подписи над ним; при вводе текста подсказка
   пропадает, при очистке поля — появляется снова. На всех трёх вкладках
   поле рассчитано так, чтобы при масштабе 100% в нём одновременно
   помещалось не менее 20 введённых символов.
2. Нажмите компактную квадратную кнопку с изображением лупы рядом с
   полем (без текстовой подписи; при наведении курсора показывается
   подсказка «Найти далее») — таблица прокрутится к первому (следующему)
   совпадению с подсветкой строки.
3. Повторные нажатия кнопки-лупы перебирают совпадения циклически.
4. Очистите поле и нажмите кнопку-лупу ещё раз — поиск сбрасывается:
   снимается выделение найденной строки и позиция навигации; если других
   активных фильтров нет, таблица показывает полную выборку, если есть —
   все строки, разрешённые этими фильтрами.

### Общий сброс

Кнопка «Сбросить всё» в конце панели каждой вкладки одним нажатием
приводит текущую вкладку в нейтральное состояние:

- очищает строку поиска, снимает выделение найденной строки и сбрасывает
  позицию навигации поиска;
- снимает выбранную группировку и разворачивает все свёрнутые группы;
- удаляет все заполненные строки динамического фильтра, оставляя одну
  пустую строку;
- на вкладке «Инструменты» дополнительно возвращает остальные фильтры
  (тип инструмента, валюта, биржа, сектор, купон, доходность и другие) в
  нейтральное состояние «Все» / пусто;
- на вкладке «Операции» дополнительно очищает оба поля периода — «Период
  с» и «Период по» — выборка возвращается к штатному состоянию с пустым
  периодом.

После сброса таблица немедленно показывает все загруженные строки без
поискового, группировочного и фильтрующего ограничения. Сортировка,
масштаб, загруженные данные и кэш справочника при сбросе не изменяются
и не перезагружаются с сервера. Сброс действует только на открытую
вкладку — состояние двух других вкладок не меняется. Повторное нажатие
«Сбросить всё» при уже нейтральном состоянии не вызывает ошибок и не
меняет полную выборку.

## Копирование текста ошибок

Текст в GUI-диалогах ошибок доступен для выделения. Выделите нужный фрагмент
и нажмите стандартную комбинацию копирования для вашей платформы (`Ctrl+C`
в Windows/Linux или `⌘C` в macOS). Сообщения об ошибке запуска также можно
скопировать этим способом.

Длинные и многострочные сообщения отображаются в прокручиваемой области
фиксированного размера и не увеличивают диалог за пределы окна. Прокрутите
область, чтобы прочитать или выделить весь текст, затем скопируйте его.

## Карточка инструмента

**Левый клик** по строке таблицы (в любой вкладке) открывает диалог
с параметрами инструмента:

- На вкладках «Портфель» и «Операции» — поля позиции/операции.
- На вкладке «Инструменты» — полные параметры из справочника API
  (для облигаций: номинал, дата погашения, амортизация, оферты).

Если доступен тикер или FIGI, в диалоге отображается ссылка
«Открыть на сайте Т-Инвестиции» → `tbank.ru`.

**Правый клик** по ячейке таблицы → «Копировать значение» — копирует
содержимое ячейки в буфер обмена.

## Экспорт

### Полный экспорт (портфель)

Кнопка «Экспорт» на вкладке «Портфель» — полный комплект отчётов,
идентичный CLI:

- `portfolio_<штамп>.json` — снимок портфеля и операции
- `portfolio_<штамп>.csv` — снимок портфеля
- `operations_<штамп>.csv` — операции
- `portfolio_<штамп>.xlsx` — лист «Портфель» + лист «Операции»

Выбирается каталог (по умолчанию — `reports_dir` из конфига). Файлы
именуются по времени и не перезаписывают предыдущие запуски.

### Экспорт текущего вида (операции, инструменты)

Кнопка «Экспорт» на вкладках «Операции» и «Инструменты» сохраняет
**текущий вид** таблицы — с применёнными динамическими фильтрами, сортировкой
и группировкой:

- `<имя>.csv` — данные таблицы (колонки + строки `dataView`,
  без заголовков групп)
- `<имя>.xlsx` — те же данные на листе «Таблица»

Диалог сохранения предлагает имя по умолчанию `table_<дата>_<время>.csv`.

## Автообновление

Если в настройках задан `auto_refresh_minutes > 0`, портфель и операции
автоматически перезагружаются с указанным интервалом. Интервал можно
изменить в любой момент через вкладку «Настройки» → «Сохранить» —
новый таймер запустится сразу. Значение `0` отключает автообновление.

## Настройки

Вкладка «Настройки» содержит форму со всеми параметрами конфигурации:

| Параметр | Элемент | Описание |
|---|---|---|
| Режим API | Выпадающий список | `prod` или `sandbox` |
| Переменная токена | Текстовое поле | Имя переменной окружения с токеном |
| Токен в конфиге | Поле с паролем | Токен напрямую (скрыт при вводе и в интерфейсе) |
| Каталог отчётов | Текстовое поле | Путь к каталогу для экспорта |
| Целевая валюта | Выпадающий список | Валюта пересчёта итогов (включает «Без пересчёта») |
| Повторы | Текстовое поле | Число дополнительных попыток API |
| Задержка повтора, мс | Текстовое поле | Базовая задержка между попытками |
| Автообновление, мин | Текстовое поле | Интервал автообновления (0 = отключено) |
| Срок кэша, ч | Текстовое поле | Срок жизни кэша справочника (TTL посегментный) |
| Тайм-аут инструментов, с | Текстовое поле | Тайм-аут полной загрузки инструментов (1–3600, default 600) |
| Тайм-аут портфеля, с | Текстовое поле | Тайм-аут загрузки портфеля (5–3600, default 180) |
| Тайм-аут дивидендов, с | Текстовое поле | Тайм-аут обогащения дивидендами (30–3600, default 900) |
| Язык | Выпадающий список | `ru` (русский) или `en` (английский) |
| Часовой пояс | Выпадающий список | UTC−23 … UTC+23 |

После нажатия «Сохранить» конфиг записывается в `config.json`,
интерфейс перестраивается с новыми настройками (язык, часовой пояс
применяются сразу; автообновление перезапускается с новым интервалом).

## Обработка ошибок

- При ошибке API/сети в GUI появляется диалог с сообщением об ошибке.
  Приложение не завершается — можно закрыть диалог и повторить операцию.
- При превышении тайм-аута портфеля или инструментов сообщение указывает,
  что прервана загрузка, действующий лимит и имя настройки для его увеличения.
- При ошибке обновления таблица не очищается: показываются лучшие доступные
  данные из кэша и успешно загруженных частей.
- При ошибке конфигурации (нет токена, неверный `mode`) GUI показывает
  ошибку при запуске или сохранении настроек.
- Токен никогда не отображается в интерфейсе, логах или экспортированных
  файлах.
