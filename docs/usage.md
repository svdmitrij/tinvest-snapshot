# Эксплуатация tinvest-snapshot (GUI)

## Запуск и первое окно

При запуске GUI открывается окно с четырьмя вкладками:

- **Портфель** — снимок портфеля (позиции, деньги, итоги)
- **Операции** — список операций за период
- **Инструменты** — поиск и фильтрация инструментов на бирже
- **Настройки** — конфигурация приложения

При первом запуске таблицы портфеля и операций пусты. Нажмите «Обновить»
на вкладке портфеля — приложение загрузит данные из API и заполнит таблицы.

## Вкладка «Портфель»

Отображает снимок всех счетов пользователя:

- **Позиции** (`position`) — строка на каждый инструмент в портфеле:
  тикер, ISIN, название, валюта, количество, средняя и текущая цена,
  стоимость, прибыль/убыток. Для облигаций — купонная ставка, доходности,
  частота и дата ближайшего купона, уровень риска. Для акций — данные
  о дивидендах.
- **Свободные деньги** (`cash`) — одна строка на валюту на каждом счёте.
- **Итог счёта** (`account_total`) — суммарная стоимость позиций и денег
  по счёту.
- **Общий итог** (`grand_total`) — сумма по всем счетам в каждой валюте.
- **Общий итог (пересчёт)** (`grand_converted`) — если задана целевая
  валюта в настройках.

Отсутствующие данные отображаются как `н/д`.

**Кнопки:**

| Кнопка | Действие |
|---|---|
| **Обновить** | Загрузить актуальные данные из API |
| **Экспорт** | Сохранить полный комплект отчётов (JSON + CSV портфеля + CSV операций + XLSX) в выбранный каталог |

## Вкладка «Операции»

Отображает список операций за период. Поля: ID, счёт, дата и время,
тип операции, инструмент, количество, сумма и валюта, статус.

**Управление периодом:**

- Поля «Период с:» и «Период по:» — задают границы выгрузки.
- Если оба поля пусты — начало периода определяется автоматически
  (по дате последнего файла отчёта или дате открытия счёта), конец —
  момент запуска.
- Дата «с» позже даты «по» — ошибка валидации в интерфейсе, запрос
  к API не выполняется.

**Кнопки:**

| Кнопка | Действие |
|---|---|
| **Обновить** | Перезагрузить портфель и операции за заданный период |
| **Экспорт** | Сохранить текущий вид таблицы операций в CSV и XLSX |

## Вкладка «Инструменты»

Поиск инструментов на бирже Т-Инвест. При первом открытии вкладки
автоматически загружаются облигации (тип по умолчанию). Остальные типы
(акции, ETF, валюты, фьючерсы) подгружаются при явном выборе; режим
**«Все»** показывает локальное объединение уже загруженных типов без
сетевых запросов. Заполните критерии и нажмите **«Поиск»** для фильтрации.

### Панель поиска

| Элемент | Назначение |
|---|---|
| **Тип инструмента** | Акции, Облигации, Фонды (ETF), Валюты, Фьючерсы, **Все** (локальное объединение загруженных типов) |
| **Строка поиска** | Поиск по тикеру, названию и ISIN (регистронезависимо, подстрока) |
| **Валюта** | Фильтр по валюте номинала |
| **Биржа** | Текстовый фильтр по бирже/площадке |
| **Сектор** | Текстовый фильтр по сектору |

### Фильтры облигаций

| Фильтр | Значения | Описание |
|---|---|---|
| **Уровень риска** | Низкий / Средний / Высокий / н/д | Уровень риска T-Invest (`riskLevel`). `н/д` выбирает инструменты без указанного уровня риска. |
| **Частота купона** | Раз в месяц / квартал / полгода / год | Периодичность купонных выплат. |
| **Тип купона** | Фиксированный / Флоатер | `floatingCouponFlag` из API. |
| **Ставка купона от/до, %** | Число | Годовая ставка купона в % к номиналу. Можно задать только нижнюю границу («от»), только верхнюю («до») или обе. Инструменты с `н/д` исключаются. |
| **Месяц купона** | Январь–Декабрь | Месяц ближайшей купонной выплаты. |
| **Дата погашения от/до** | Выпадающий список (значения из таблицы) | Диапазон дат погашения. Дата погашения = ближайшая будущая оферта, при её отсутствии — штатная дата из API. Облигации без даты погашения отображаются только когда оба поля пусты. |

### Фильтры акций

| Фильтр | Значения | Описание |
|---|---|---|
| **Дивиденды** | Да / Нет | Наличие дивидендных выплат за последние 12 месяцев. |

Все фильтры комбинируются: результат содержит только инструменты,
удовлетворяющие **всем** заданным условиям (логическое И).

### Кэш и обновление справочника

Справочник состоит из пяти сегментов (облигации, акции, ETF, валюты,
фьючерсы). Каждый сегмент имеет свою временную метку; TTL
(`catalog_ttl_hours`) проверяется независимо для каждого сегмента.

- **Первое открытие** вкладки — загружаются только облигации.
  Остальные типы подгружаются лениво при выборе.
- **Кнопка «Обновить»** при конкретном типе перезагружает только его;
  остальные сегменты не затрагиваются.
- **«Обновить» в режиме «Все»** принудительно загружает все пять
  типов с независимой атомарностью: успешные сохраняются, при сбое
  одного остальные не затрагиваются.
- **Тайм-ауты:** для облигаций — `instrument_load_timeout_seconds`
  (по умолчанию 600 с, допустимо 1–3600 с), для остальных типов — 30 с,
  для дивидендного обогащения акций — `dividend_load_timeout_seconds`
  (по умолчанию 900 с). Значение таймаута загрузки инструментов вне диапазона
  нормализуется к 600 с.
- При переключении на уже загруженный тип сетевые запросы не выполняются.

Под панелью фильтров отображается время последнего обновления
(в часовом поясе из настроек) — для сегмента облигаций.

**Кнопки:**

| Кнопка | Действие |
|---|---|
| **Поиск** | Выполнить поиск с заданными фильтрами |
| **Обновить** | Принудительно перезагрузить текущий тип (или все типы в режиме «Все») |
| **Экспорт** | Сохранить текущий вид результатов в CSV и XLSX |

## Работа с таблицами

Все таблицы в GUI (портфель, операции, инструменты) имеют единый набор
операций:

### Сортировка

Клик по заголовку колонки сортирует строки по этой колонке. Повторный
клик меняет направление: ▲ (по возрастанию) ↔ ▼ (по убыванию). Числовые
значения сортируются как числа, текстовые — лексикографически.

### Фильтрация по колонке

1. Выберите колонку в выпадающем списке «Фильтр колонки».
2. Введите значение в поле справа.
3. Таблица обновится — останутся только строки, где выбранная колонка
   содержит введённую подстроку (регистронезависимо).
4. Очистите поле — фильтр снимется, отобразятся все строки.

### Группировка

1. Выберите колонку в выпадающем списке «Группировать по».
2. Строки сгруппируются по значению выбранной колонки.
3. Клик по заголовку группы (▾ `Группа: значение`) сворачивает группу
   (остаётся только заголовок с ▸). Повторный клик — разворачивает.
4. Выберите пустое значение в списке — группировка снимается.

### Текстовый поиск

1. Введите текст в поле «Поиск по таблице».
2. Нажмите «Найти далее» — таблица прокрутится к первому (следующему)
   совпадению с подсветкой строки.
3. Повторные нажатия «Найти далее» перебирают совпадения циклически.
4. Очистите поле — поиск сбрасывается.

## Копирование текста ошибок

Текст в GUI-диалогах ошибок доступен для выделения. Выделите нужный фрагмент
и нажмите стандартную комбинацию копирования для вашей платформы (`Ctrl+C`
в Windows/Linux или `⌘C` в macOS). Сообщения об ошибке запуска также можно
скопировать этим способом.

Длинные и многострочные сообщения отображаются в прокручиваемой области
фиксированного размера и не увеличивают диалог за пределы окна. Прокрутите
область, чтобы прочитать или выделить весь текст, затем скопируйте его.

## Карточка инструмента

**Левый клик** по строке таблицы (в любой вкладке) открывает диалог
с параметрами инструмента:

- На вкладках «Портфель» и «Операции» — поля позиции/операции.
- На вкладке «Инструменты» — полные параметры из справочника API
  (для облигаций: номинал, дата погашения, амортизация, оферты).

Если доступен тикер или FIGI, в диалоге отображается ссылка
«Открыть на сайте Т-Инвестиции» → `tbank.ru`.

**Правый клик** по ячейке таблицы → «Копировать значение» — копирует
содержимое ячейки в буфер обмена.

## Экспорт

### Полный экспорт (портфель)

Кнопка «Экспорт» на вкладке «Портфель» — полный комплект отчётов,
идентичный CLI:

- `portfolio_<штамп>.json` — снимок портфеля и операции
- `portfolio_<штамп>.csv` — снимок портфеля
- `operations_<штамп>.csv` — операции
- `portfolio_<штамп>.xlsx` — лист «Портфель» + лист «Операции»

Выбирается каталог (по умолчанию — `reports_dir` из конфига). Файлы
именуются по времени и не перезаписывают предыдущие запуски.

### Экспорт текущего вида (операции, инструменты)

Кнопка «Экспорт» на вкладках «Операции» и «Инструменты» сохраняет
**текущий вид** таблицы — с применёнными фильтрами, сортировкой
и группировкой:

- `<имя>.csv` — данные таблицы (колонки + строки `dataView`,
  без заголовков групп)
- `<имя>.xlsx` — те же данные на листе «Таблица»

Диалог сохранения предлагает имя по умолчанию `table_<дата>_<время>.csv`.

## Автообновление

Если в настройках задан `auto_refresh_minutes > 0`, портфель и операции
автоматически перезагружаются с указанным интервалом. Интервал можно
изменить в любой момент через вкладку «Настройки» → «Сохранить» —
новый таймер запустится сразу. Значение `0` отключает автообновление.

## Настройки

Вкладка «Настройки» содержит форму со всеми параметрами конфигурации:

| Параметр | Элемент | Описание |
|---|---|---|
| Режим API | Выпадающий список | `prod` или `sandbox` |
| Переменная токена | Текстовое поле | Имя переменной окружения с токеном |
| Токен в конфиге | Поле с паролем | Токен напрямую (скрыт при вводе и в интерфейсе) |
| Каталог отчётов | Текстовое поле | Путь к каталогу для экспорта |
| Целевая валюта | Выпадающий список | Валюта пересчёта итогов (включает «Без пересчёта») |
| Повторы | Текстовое поле | Число дополнительных попыток API |
| Задержка повтора, мс | Текстовое поле | Базовая задержка между попытками |
| Автообновление, мин | Текстовое поле | Интервал автообновления (0 = отключено) |
| Срок кэша, ч | Текстовое поле | Срок жизни кэша справочника (TTL посегментный) |
| Тайм-аут инструментов, с | Текстовое поле | Тайм-аут загрузки облигаций (30–3600, default 600) |
| Тайм-аут дивидендов, с | Текстовое поле | Тайм-аут обогащения дивидендами (30–3600, default 900) |
| Язык | Выпадающий список | `ru` (русский) или `en` (английский) |
| Часовой пояс | Выпадающий список | UTC−23 … UTC+23 |

После нажатия «Сохранить» конфиг записывается в `config.json`,
интерфейс перестраивается с новыми настройками (язык, часовой пояс
применяются сразу; автообновление перезапускается с новым интервалом).

## Обработка ошибок

- При ошибке API/сети в GUI появляется диалог с сообщением об ошибке.
  Приложение не завершается — можно закрыть диалог и повторить операцию.
- При ошибке конфигурации (нет токена, неверный `mode`) GUI показывает
  ошибку при запуске или сохранении настроек.
- Токен никогда не отображается в интерфейсе, логах или экспортированных
  файлах.
